## What Changed

The entire CADMIES blockstore was regrown from source concept JSONs on a fresh Paperspace machine (A4000) after the previous instance was wiped during a billing scare. All 659 concepts were re-minted with new CIDs, the index was rebuilt from scratch, and the two Hieros-era genesis blocks were resolved. A full disaster-recovery tarball was created and pushed to GitHub.

The mycelium now exists in three places: live on Paperspace, as spores (source JSONs) in the repo, and as a complete tarball in git.

## Why

The Paperspace machine was intentionally wiped to avoid data loss from non-payment. Investigation revealed no CAR file, no tarball, and no other backup of the blockstore existed. However, `store/blocks/` is gitignored, so the blockstore was never in git — but `source_concepts/` was fully tracked and survived intact. Following the Phase 57 precedent, source concepts are the ground truth: every other artifact (blocks, index, backups) can be regenerated from them.

The rebuild also surfaced and resolved two legacy issues: the two extension-less genesis blocks that had haunted orphan checks since the beginning, and 35 source files carrying legacy-format human_ids rejected by the validator.

## Analysis

The root failure was procedural, not technical: no disaster-recovery backup ritual existed. The system's own design saved it — content-addressed storage with tracked source files means the blockstore is fully derivable from its DNA. The rebuild also exposed latent debt: a schema file containing a copied script instead of a schema (never enforced at runtime, so never noticed), and legacy human_ids persisting in source files after the Phase 57 block-level cleanup. Both are documented and deferred to the legacy source cleanup phase.

New cardinal rule established: every session ends with a tarball export.

## Conclusion

The mycelium regrew from spores. All addresses are new, but all knowledge survived. The backup discipline that should have existed from the start is now in place, and GitHub serves as a genuine full-recovery point.
